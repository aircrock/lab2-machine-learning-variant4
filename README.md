# Лабораторная работа №2 — вариант 4

**Тема:** обучение без учителя, понижение размерности и кластеризация.

Работа состоит из двух частей: анализ признаков методами PCA, SVD и ICA, затем сравнение алгоритмов кластеризации и поиск возможных выбросов.

## Файлы проекта

```text
lab2_variant4.py
Lab2_Dataset_PCA.xlsx
Lab2_Dataset_Clustering.xlsx
README.md
output/
```

В `output` находятся только графики в формате PNG. Таблицы с метриками и значения важности компонент выводятся в терминал при запуске.

## Установка

Нужен Python 3.10 или новее. Установить библиотеки:

```bash
pip install numpy pandas matplotlib scipy scikit-learn openpyxl
```

Если используется старая версия `scikit-learn`, в которой нет `HDBSCAN`, дополнительно установить:

```bash
pip install hdbscan
```

## Запуск

1. Поместить оба Excel-файла рядом с `lab2_variant4.py`.
2. Открыть терминал в папке проекта.
3. Выполнить команду:

```bash
python lab2_variant4.py
```

После выполнения в папке `output` появятся графики:

- `01_correlation.png` — корреляции признаков;
- `02_scatter_matrix.png` — матрица разброса;
- `03_pca_importance.png`, `04_svd_importance.png`, `05_ica_importance.png` — значимость компонент;
- `06_pca_projection.png`, `07_svd_projection.png`, `08_ica_projection.png` — двумерные проекции;
- `09_all_algorithms.png` — сравнение 12 алгоритмов кластеризации;
- `10_density_methods.png` — DBSCAN, HDBSCAN и OPTICS;
- `11_anomalies.png` — точки, отнесённые DBSCAN к шуму;
- `12_gmm_reference.png` — сравнение GMM с эталонной разметкой.

## Используемые данные

Для PCA используются столбцы **S:X** из `Lab2_Dataset_PCA.xlsx` (признаки `a`–`e` и метки `y`). Для кластеризации — **J:L** из `Lab2_Dataset_Clustering.xlsx` (признаки `a`, `b` и метки `y`). Пустые строки пропускаются.

Признаки перед анализом стандартизируются. Метки `y` не участвуют в обучении моделей: они нужны только для окраски графиков и сравнения кластеризации с правильной разметкой.

## Краткие результаты

В данных PCA заметнее всего связаны признаки `a` и `c` (коэффициент корреляции около 0,544). Первые четыре компоненты PCA объясняют примерно 91,51% общей дисперсии; последняя компонента даёт около 8,49%.

В кластеризации лучше всего показала себя смесь гауссовых распределений (`Gaussian Mixture`) с полной ковариационной матрицей. Для данных варианта 4 получено ARI около 0,561. Плотностные методы выделяют часть точек как шум, но отдельного класса аномалий в эталонных данных нет, поэтому эти точки нельзя однозначно считать выбросами.
